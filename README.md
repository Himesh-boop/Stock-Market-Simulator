# Stock Market Simulator

## Overview

The **Stock Market Simulator** is a desktop-based application developed using **C++**, **Qt framework**, and **SQLite** for local data storage. It is designed to provide users especially students and beginner investors with a realistic yet risk-free platform to understand the fundamentals of stock trading.

Unlike real-time platforms involve actual money, this simulator uses **virtual currency** and **real-time scraped stock data** to emulate market behavior. It enables users to buy and sell stocks, track their portfolio performance, and all within a safe and educational environment.

---

## Features

- 💰 **Virtual Trading**: Trade stocks using simulated money without any financial risk.
- 📈 **Live Stock Price Updates**: Real-time prices fetched using Python web scraping from [merolagani.com](https://merolagani.com/).
- 🧾 **Portfolio Management**: Monitor holdings, transaction history, gains/losses, and overall performance.
- 💻 **User-Friendly GUI**: Built using the Qt framework for a clean and interactive desktop experience.
- 🗃️ **Local Database Support**: Stores all user data using SQLite for quick access and offline capability.

---

## Tools and Technologies

- **Programming Language**: C++
- **UI Framework**: Qt (Qt Widgets)
- **Database**: SQLite
- **Web Scraping**: Python (for data collection from merolagani.com)
